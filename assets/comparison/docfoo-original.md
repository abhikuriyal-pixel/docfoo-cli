The claim is only partly correct. Longformer and BigBird sparsify the attention pattern, so they reduce attention arithmetic by omitting many token-to-token connections. FlashAttention does **not** drop connections: it computes exact, full attention while reducing memory use and high-bandwidth-memory (HBM) traffic. [Papers/longformer/content.md:87-87] [Papers/flash-attention/content.md:105-159]

In the original Transformer, full self-attention has \(O(n^2)\) time and memory complexity in sequence length \(n\). Every token can attend directly to every other token, so the maximum attention-path length is 1. [Papers/longformer/content.md:13-39] [Papers/attention-is-all-you-need/content.md:117-123]

Longformer replaces full attention with local sliding-window attention plus task-selected global attention. With window width \(w\), each token attends to \(w/2\) tokens on each side; the local computation is \(O(n \times w)\), and the receptive field grows across layers. Dilation spaces out the window connections, increasing receptive field without increasing computation; for fixed dilation \(d\) and \(w\), the stated receptive field is \(\ell \times d \times w\) over \(\ell\) layers. Global attention is symmetric: global tokens attend to the whole sequence, and all tokens attend to them. This supplies long-range routes, with combined local/global attention still \(O(n)\) when the number of global tokens is small and independent of \(n\). [Papers/longformer/content.md:91-117]

BigBird combines local-window, random, and global connections. Its global tokens can be existing tokens (ITC) or additional tokens (ETC); the paper says the added ETC tokens provide extra context storage and improve performance in experiments. [Papers/big-bird/content.md:15-41] [Papers/big-bird/content.md:97-101] Its theoretical claims are conditional: the universality result uses a sparse graph containing a star graph, and the Turing-completeness result is for a sparse attention mechanism using \(O(n)\) inner products, under the paper’s stated precision assumptions. [Papers/big-bird/content.md:718-730] [Papers/big-bird/content.md:793-799] These are expressivity guarantees, not a claim that sparse attention reproduces every full-attention computation at the same cost.

FlashAttention instead tiles \(Q,K,V\), computes attention block by block, and combines block results using normalization statistics. It avoids storing the \(O(N^2)\) intermediate attention matrices: the paper states \(O(N)\) additional memory beyond inputs and output. For the backward pass, it recomputes attention intermediates from stored inputs, output, and statistics rather than storing them. The result remains exact, with \(O(N^2d)\) FLOPs; tiling and recomputation target HBM accesses, not quadratic arithmetic. [Papers/flash-attention/content.md:105-159]

So the costs differ: Longformer and BigBird reduce arithmetic by using sparse connectivity; FlashAttention preserves quadratic arithmetic and all-pairs interaction, while reducing additional memory and HBM traffic. If every token pair must still interact, use **FlashAttention**: it retains exact attention rather than approximating it by dropping connections. [Papers/flash-attention/content.md:105-159]

The evidence gives complexity and connectivity descriptions but does not state a numeric maximum path length for Longformer or BigBird; those depend on the specific attention pattern and layers.
