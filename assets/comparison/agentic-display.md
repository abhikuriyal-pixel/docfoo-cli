The claim is **only partly correct**. Longformer and BigBird reduce attention’s arithmetic by restricting which token pairs interact. **FlashAttention does not drop pairs**: it computes exact dense attention, reducing memory traffic and memory use, not the quadratic attention arithmetic.

Original self-attention has \(O(n^2d)\) computation per layer, \(O(1)\) sequential operations, and maximum path length \(O(1)\): every position can directly reach every other in one layer. Restricting it to a neighborhood of size \(r\) lowers the tabulated cost to \(O(rnd)\), but raises maximum path length to \(O(n/r)\). [attention-is-all-you-need/content.md:147-147] The paper explains that shorter dependency paths can help learning long-range dependencies. [attention-is-all-you-need/content.md:167-169]

A fixed sliding window lets each token attend only nearby positions. Stacked layers expand the receptive field, so distant tokens can influence one another indirectly, rather than through a single direct connection. [longformer/content.md:91-91] Dilation inserts gaps in that window, increasing receptive field without increasing computation; with fixed dilation \(d\), window \(w\), and \(\ell\) layers, the paper gives receptive field \(\ell dw\). [longformer/content.md:101-103] Neither local nor dilated attention alone guarantees direct all-pairs access in one layer. Longformer adds *symmetric* global attention at selected tokens: global tokens attend to all positions, and all positions attend to them. These hubs provide a route between distant tokens, but do not make every ordinary token pair directly connected. [longformer/content.md:107-107]

BigBird combines a local window, a fixed number of random connections per query, and global tokens. [big-bird/content.md:101-101] This adds random long-range links to local structure and global routes; it remains sparse rather than restoring the full attention matrix. Its universal-approximation result has a specific condition: the attention graph must contain a star graph (enabled by global connectivity); it is not an unconditional claim that any sparse pattern matches full attention. [big-bird/content.md:123-125] The Turing-completeness result also assumes standard precision conditions, as the paper’s summary states. [big-bird/content.md:37-37] The paper also notes a “no free lunch”: some tasks solved by full attention in constant layers require near-linear-in-\(n\) layers for sufficiently sparse mechanisms, under stated complexity assumptions. [big-bird/content.md:151-159]

Tiling loads blocks of \(Q,K,V\) into fast SRAM and accumulates correctly normalized partial results; recomputation in the backward pass avoids storing the full attention matrix. This preserves exact attention. [flash-attention/content.md:107-107] [flash-attention/content.md:131-133] Its attention arithmetic remains quadratic in sequence length; its benefit is fewer HBM reads/writes and linear memory footprint, not linear FLOPs. The paper reports quadratic runtime growth, but linear memory growth. [flash-attention/content.md:285-287] It also gives subquadratic HBM-access complexity for its tiled algorithm. [flash-attention/content.md:173-175]

if every token pair must interact, use exact dense attention with FlashAttention (or an equivalent IO-aware implementation). It preserves all pairwise interactions while reducing memory-access overhead and avoiding quadratic intermediate storage; it does **not** eliminate quadratic arithmetic. [flash-attention/content.md:31-33]
